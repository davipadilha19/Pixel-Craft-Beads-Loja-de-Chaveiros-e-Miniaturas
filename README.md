👾 Pixeland — Landing Page (Hama Beads)

Projeto de uma Landing Page responsiva e semântica desenvolvida para a loja Pixeland, especializada em chaveiros, miniaturas e artes artesanais feitas em Hama Beads (Pixel Art).

Este trabalho foi desenvolvido como avaliação N2 para a disciplina de Ferramentas Web e UX, ministrada pelo professor Luiz Almeida Junior, no curso de Bacharelado da Faculdade Católica de Santa Catarina (Católica SC) - Campus Jaraguá do Sul.

📌 Sobre o Projeto

O objetivo principal deste projeto é criar uma experiência de usuário (UX) moderna, intuitiva e acessível para a apresentação e encomenda de produtos artesanais geek em pixel art. A aplicação foi construída priorizando a semântica do HTML5, a responsividade com CSS puro e a inclusão de funcionalidades focadas na experiência do usuário (como Dark Mode e navegação direta via WhatsApp).

🎯 Principais Funcionalidades

Layout Responsivo: Adaptado para telas Desktop, Tablets e Celulares (Mobile First/Media Queries).

Dark Mode (Tema Escuro): Alternância dinâmica de cores entre tema claro e escuro usando Variáveis CSS e JavaScript.

Integração com WhatsApp: Formulário de encomenda interativo e botões de catálogo que disparam mensagens pré-formatadas via URL (wa.me) sem necessidade de back-end.

Navegação Semântica: Utilização das tags HTML5 adequadas (header, main, section, article, details/summary, footer) otimizadas para SEO e acessibilidade.

Seção FAQ Interativa: Sistema de perguntas e respostas sanfonado usando a tag nativa <details>.

🛠️ Tecnologias Utilizadas

HTML5: Estrutura semântica e acessível.

CSS3: Estilização, layout flexível (Flexbox e CSS Grid), variáveis de ambiente e Media Queries para responsividade.

JavaScript (ES6): Manipulação leve do DOM para alternância do tema escuro/claro.

Abra o arquivo index.html em qualquer navegador moderno ou execute através da extensão Live Server no VS Code.
